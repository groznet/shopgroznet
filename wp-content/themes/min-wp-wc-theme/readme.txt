== Description ==

Min is an HTML-first, minimal-CSS WordPress and WooCommerce theme. It leans on
semantic markup and the browser's own default rendering for structure and
spacing; CSS is used only where HTML and normal document flow genuinely
cannot do the job (fluid widths, media sizing, overflow handling, a small
number of layout adjustments). No CSS framework, icon library, or animation
library is used, and the theme adds no custom JavaScript beyond what
WooCommerce itself needs.

== Installation ==

1. Upload the theme folder to `/wp-content/themes/`.
2. Activate the theme through the 'Appearance' menu in WordPress.
3. Install and activate WooCommerce for shop functionality.
4. Assign a Primary Menu and, optionally, a Footer Menu under Appearance > Menus.

== Frequently Asked Questions ==

= Does this theme support WooCommerce? =

Yes, out of the box: shop, product archives/categories/tags, single products
(including variable products), cart, checkout, My Account, search and
related/upsell/cross-sell products all work through WooCommerce's own
templates, styled by the theme's single stylesheet.
